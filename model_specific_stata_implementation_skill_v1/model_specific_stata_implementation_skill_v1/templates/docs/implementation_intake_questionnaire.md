# Implementation Intake Questionnaire

Before implementing the Stata models, ask the user to confirm:

1. Which dataset should be used as `analysis_ready.dta`?
2. Which `stata_command_plan.csv` should be used?
3. Which hypotheses and dependent variables should be included in the main tables?
4. Which controls survived the bad-control audit and should appear in the main result tables?
5. Which fixed effects and clustering dimensions are approved?
6. Which community commands are approved, if any?
7. Which Stata version will run the code?
8. Should controls be included in the main tables, appendices, or both? Default: include controls in the main result tables.
9. Which robustness checks and additional analyses should be implemented now?
10. Which output formats are required: `.tex`, `.docx`, `.xlsx`, `.csv`, `.smcl`, `.log`, `.png`, `.pdf`?
