# Endogeneity Quality Gate

Codex must verify all items before reporting results.

- [ ] Each focal relationship has an identified endogeneity threat or is marked as no current endogeneity concern.
- [ ] Every method maps to a threat.
- [ ] User approved the threat-to-method map.
- [ ] Manual/help sources were retrieved or checked.
- [ ] Controls are pre-treatment or otherwise justified.
- [ ] Bad controls, mediators, and colliders are excluded from the main correction model.
- [ ] FE/HDFE identifying variation was checked.
- [ ] Cluster level was justified.
- [ ] IV has an instrument validity memo and first-stage/reduced-form diagnostics.
- [ ] DID has pre-period, control group, pretrend/anticipation diagnostics, and treatment timing audit.
- [ ] Matching/weighting has overlap and balance diagnostics.
- [ ] Dynamic panel has AR and overidentification diagnostics and instrument-count audit.
- [ ] Sample-selection model has a selection equation and exclusion rationale.
- [ ] Measurement-error strategy has construct-validity support.
- [ ] Specification changes were approved and logged.
- [ ] Results tables include controls or user-approved appendix-only control reporting.
- [ ] Interpretation avoids saying endogeneity has been “solved.”
