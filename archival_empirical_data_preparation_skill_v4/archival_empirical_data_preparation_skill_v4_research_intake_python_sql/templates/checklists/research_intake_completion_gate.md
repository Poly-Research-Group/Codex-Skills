# Research Intake Completion Gate

Codex must answer yes to each item before preparing data.

## Context and hypotheses

- [ ] Can Codex summarize the empirical context and focal phenomenon in one paragraph?
- [ ] Can Codex state the main research question?
- [ ] Is there at least one hypothesis or explicitly exploratory empirical relationship?
- [ ] Does each hypothesis have a dependent construct and key explanatory construct, treatment, event, moderator, mediator, or mechanism?

## Unit, time, and data structure

- [ ] Is the final unit of analysis defined?
- [ ] Is the data structure defined as cross-sectional, panel, repeated cross-sectional, event-time, cohort-time, transaction-level, or session-level?
- [ ] Are unit identifiers known or constructible?
- [ ] Are time identifiers known or constructible when the data have a time dimension?
- [ ] Is the observation window specified or explicitly assumed?

## Sources and variables

- [ ] Are raw sources listed with coverage, raw unit, raw time grain, and known limitations?
- [ ] Are expected merge keys specified?
- [ ] Are dependent variables, key independent variables, moderators, mediators/mechanisms, controls, fixed effects, and clustering candidates classified?
- [ ] Are manuscript-facing summary-statistics variables specified or marked for later selection?

## Timing and identification

- [ ] Is temporal ordering clear for all focal variables?
- [ ] Are candidate controls classified as pre-treatment, predetermined, time-invariant, contemporaneous, post-treatment, mechanism-only, or excluded?
- [ ] Are post-treatment control, collider, mechanical-overlap, and fixed-effect absorption risks identified?
- [ ] Are treatment/event timing rules specified if relevant?

## Approval

- [ ] Has the user confirmed the research-design summary, or explicitly approved documented assumptions?
