## Time window

Default to the rolling ten years ending on the search date. If the database only supports year filters, use the nearest inclusive publication-year approximation and record the limitation in the search log.

## Out-of-scope papers

Papers outside this journal basket should not enter the main synthesis matrix unless the user approves an expanded scope. If useful, they may be listed in a separate "outside-scope background" section, clearly labeled.
