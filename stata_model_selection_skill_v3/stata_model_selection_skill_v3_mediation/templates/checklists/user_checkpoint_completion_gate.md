# User Checkpoint Completion Gate

Before exporting the final model-selection package, Codex must verify:

- [ ] C0 Intake confirmation completed or explicitly skipped with assumptions logged.
- [ ] C1 Upstream readiness checkpoint completed or explicitly skipped with assumptions logged.
- [ ] C2 Outcome and data-structure classification checkpoint completed or explicitly skipped with assumptions logged.
- [ ] C3 Identification and estimand checkpoint completed or explicitly skipped with assumptions logged.
- [ ] C4 Primary-estimator shortlist checkpoint completed or explicitly skipped with assumptions logged.
- [ ] C5 Specification-strategy checkpoint completed or explicitly skipped with assumptions logged.
- [ ] C6 Community-command checkpoint completed if any user-written Stata command is recommended.
- [ ] C7 Robustness and reporting checkpoint completed or explicitly skipped with assumptions logged.
- [ ] Any skipped checkpoint is recorded in `docs/assumptions_and_decision_log.md`.
- [ ] Any final recommendation affected by skipped checkpoints is labeled `conditional`.
