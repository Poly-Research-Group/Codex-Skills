# Hard Stop Checklist

Stop before model selection if any box is checked and unresolved:

- [ ] Undefined unit of analysis.
- [ ] Nonunique row key without explanation.
- [ ] Missing outcome or key IV/treatment variable.
- [ ] Ambiguous treatment/event timing.
- [ ] Treatment constructed with future outcome information.
- [ ] DID/event study lacks pre-period or comparison units.
- [ ] Main model includes post-treatment controls without explicit design rationale.
- [ ] Sample restrictions cannot be reconstructed.
- [ ] Key variables have severe unexplained missingness.
- [ ] Intended fixed effects absorb the key variable.
- [ ] Identification depends on undocumented instrument, cutoff, or event.
